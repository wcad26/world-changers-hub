

## Add Event Page URL and Attendance URL Fields to Super Admin Event Dialogs

This change adds two new URL input fields to the Create Event and Edit Event dialogs in the Super Admin Events page, allowing executives to specify:

1. **Event Page URL** -- an external link to the event's dedicated page (uses the existing `registration_url` column on the `events` table)
2. **Attendance Submission URL** -- a custom URL for attendance submission (auto-populated with the system-generated `/attend/:eventId` link, but editable)

### What Changes

**File: `src/pages/admin/super/Events.tsx`**

- Add two new fields to `eventSchema`: `registration_url` (optional URL string) and `attendance_url` (optional URL string)
- Add two new `FormField` inputs in the shared `renderEventForm` function, placed after the Address field, with labels "Event Page URL" and "Attendance Submission URL"
- In `onSubmit` (create): pass `registration_url` to the create mutation. For attendance URL, auto-generate the `/attend/:eventId` link after creation (since the event ID isn't known yet, this will be shown as read-only in edit mode only)
- In `openEditDialog`: pre-fill both fields -- `registration_url` from the event data, and auto-populate the attendance URL with the system-generated `/attend/:eventId` link
- In `onEditSubmit`: pass `registration_url` to the update mutation

### Technical Details

- The `registration_url` column already exists on the `events` table -- no database migration needed
- The attendance submission URL (`/attend/:eventId`) is auto-generated by the system and displayed as a read-only, copyable field in the edit dialog. For the create dialog it won't be shown since the event ID doesn't exist yet
- Both URLs are optional fields with URL format validation via Zod (`.url().optional().or(z.literal(""))`)
- The `useCreateGlobalEvent` and `useUpdateGlobalEvent` hooks already pass through all fields to Supabase, so no hook changes are needed

### No Database Changes Required

The `registration_url` column already exists on the `events` table. The attendance link is computed from the event ID, not stored separately.
